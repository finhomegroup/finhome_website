# Arithmetic living-infographic release

## Scope

Three approved mechanisms, not the same picture with different labels:

- `tinh-phan-tram`: a common signed ruler for the active question; named denominator,
  distinct percentage versus percentage-point units, observer and reversible trial.
- `margin-va-markup`: the same profit on two separately labelled denominator scales
  (sale price and cost); explicit loss/negative-sale-price explanation.
- `giam-gia-va-thue`: the engine's sequential ledger on a fixed bill scale;
  included tax is a composition, excluded tax is an addition.

The retained Claude implementation session owns source and repairs. Codex independently
reviewed and integrated the allowlisted files into the release checkout, based on
main `72a6dc6`. Shared interaction foundations already shipped in PR #214.
The three engines, parser domains, defaults, dependencies and legal copy are unchanged.
The user authorized incremental scoped PRs and merge after green checks.

## Repairs covered

Worked percentage equations retain distinct near-equal operands. More than ten
decimal places produces a named equation limitation, not false zero arithmetic.
Repeating results are marked approximate. Non-finite computed outputs withhold
drawings, comparisons and profit verdicts; trial buttons are disabled. Form-return
actions target a numeric field, not the mode radio. Both price-ledger monetary
columns use the existing typed-cell unit toggle consistently.

- Percentage: 30 → 40% changes 600 → 800 million; undo restores 30%. Observer

  Points 7.001 → 7.002 show the distinct operands and 0.001-point difference.
  0 → 1e−11 names the equation precision limit without making the result zero.
  A zero share denominator focuses the invalid field; 1/3 recovers with an
  approximately 33.3333333333% equation.
- Margin: a 10% sale-price trial gives 900,000 price, 300,000 profit, 33.33% margin
  and 50% markup; undo restores the default. −300,000 sale price shows −900,000
  loss, +300% margin and −150% markup with an explicit warning. Cost 1e308 and
  markup 100 show a computation limit, no profit verdict, and a cost-field recovery.
- Price: observer on the second discount explains 10% of 800,000. Voucher 50,000
  changes final 720,000 → 670,000; switching to excluded tax gives 723,600; two
  undos restore 720,000. Voucher 800,000 refuses the combination and offers a real
  field jump. 100% first discount is a valid zero. Compact and full-dong ledger
  columns remain consistent.
- Viewed states had no document-level horizontal overflow. Each route retained one
  result live region; interactive learning controls remain outside it. Screenshot
  inspection covered labels, signed bars and the price-path composition. Captured
  console error list was empty at final price review.

These are bounded desktop-browser viewport checks, not physical-device, spoken
